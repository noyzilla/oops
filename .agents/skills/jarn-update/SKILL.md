# Jarn Update & Impact Analysis Runbook [คู่มือการอัพเดทและวิเคราะห์ผลกระทบ Jarn]

This skill defines the autonomous procedure to update the Jarn framework (rules and skills) and analyze the impact of those updates on the current project.

## When to Use This Skill [เมื่อใดควรใช้สกิลนี้]

Activate this workflow when:
- The user requests to update Jarn (e.g. "update jarn", "/jarn-update").
- A new version of Jarn is known to be available and needs to be pulled.

## Operational Execution Runbook [ขั้นตอนการปฏิบัติงาน]

### 1. Execute the Updater Script [รันสคริปต์อัพเดท]
- Run `./.agents/scripts/jarn-update.sh` in the terminal.
- Wait for the script to finish and check the exit code. If it fails, report the error to the user immediately.

### 2. Analyze Changes & Migration Instructions [วิเคราะห์ผลกระทบและคำแนะนำจากอัพเดท]
- Run `git status` and `git diff` on the `.agents/` directory to see which rules or skills were added, modified, or deleted.
- If there are no changes, inform the user that Jarn is already up to date.
- **Read Official Update Instructions**: Carefully read the terminal output generated by `./.agents/scripts/jarn-update.sh`. The updater script is responsible for fetching and displaying the official release notes and migration instructions directly in the console. Use this output to understand the explicit recommendations provided by the Jarn maintainers. (There will be no permanent update notes file left in the project).
- Check if the updated rules conflict with or require changes in the project's current documentation (e.g. `AGENTS.md`, `REVIEW.md`, `CONTRIBUTING.md`) or existing code practices.
- **Anti-Duplication Audit**: Ensure that project root documents do not contain hardcoded copies of Jarn rules. If any rule is found duplicated (e.g., Gate checklists copied directly into `REVIEW.md`), flag it as an impact and recommend removing the duplication in favor of a direct reference link to the central `.agents/rules/jarn-*.md` files.

### 3. Report and Follow-up [รายงานและดำเนินการต่อ]
- Present a clear summary of what Jarn files were updated.
- **Relay Official Recommendations**: Present the exact recommendations or migration steps that were captured from the updater script's terminal output.
- **Actionable Impact Notification**: If the updates or the official recommendations impact the current project, you MUST proactively notify the user with a specific recommendation. (e.g., *"ในอัพเดทนี้ สคริปต์ได้แจ้งคำแนะนำให้แก้ไฟล์ CONTRIBUTING.md ผมวิเคราะห์แล้วพบว่ากระทบกับโปรเจกต์เรา ให้ผมจัดการแก้ตามคำแนะนำเลยไหมครับ?"*).
- Highlight any **breaking changes** or new rules that the project needs to adopt.
- If adjustments to the project are needed to comply with the updated Jarn rules, ask the user for permission to apply the fixes automatically (or proceed if already given explicit directive).
