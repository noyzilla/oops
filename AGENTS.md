# Repository Guidelines & Standards

## Documentation & Commenting Rules
- Do NOT use numbered steps (e.g., 1., 2., 3., or ### 1.) in documentation, markdown files, plans, walkthroughs, or code comments.
- Use descriptive headings, unnumbered bullet points, and intent-based/action-based code comments instead.
- Do NOT use emojis or decorative icons in technical documentation or codebase comments.
